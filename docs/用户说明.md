# product-feed-kr 用户说明

本文档面向**使用本仓库脚本**的同事或合作方：在 Windows 上解压源码、安装依赖、配置密钥后，通过 **`.bat`** 完成微猫抓取、SQLite 内 LLM 润色、seven17 上架等流程。

---

## 1. 环境与目录要求

- **操作系统**：Windows 10 / 11（64 位）。
- **Python**：3.10 及以上（推荐 3.12）。若未安装，可用 **`test\setup_venv.bat`** 尝试自动安装（见下文）。
- **磁盘**：建议预留足够空间存放 SQLite、日志与图片缓存。
- **网络**：安装依赖时需访问 PyPI（已配置**清华大学镜像**）；运行抓取/上架时需能访问微猫与 seven17 等站点。

解压后**仓库根目录**应能看到例如：

- `product_feed_kr/`：Python 源码包  
- `config/seven17.example.json`：配置模板（**勿**把含密码的 `seven17.json` 提交到 Git）  
- `config/pip_tsinghua.ini`：pip 使用清华源的说明文件（由 `test\setup_venv.bat` 引用）  
- `requirements.txt`：依赖列表  
- **`test\setup_venv.bat`**：一键创建虚拟环境并安装依赖  
- **`01_采集微猫店铺.bat`**、**`02_LLM补全上架信息.bat`**、**`03_上传韩国站正式.bat`**、**`04_无价格白名单设置.bat`**（核心业务入口）

业务脚本统一使用根目录下的 **`venv\Scripts\python.exe`**，**不要**混用系统全局 Python，以免缺包或版本不一致。

---

## 2. 第一次安装（推荐）

1. 将整个文件夹解压到**不含中文、尽量不含空格**的路径（例如 `D:\work\product-feed-kr`）。  
2. 双击运行 **`test\setup_venv.bat`**。脚本会：  
   - 若已存在 **`config\pip_tsinghua.ini`**，则设置 `PIP_CONFIG_FILE`，使 **pip 走清华源**；  
   - 若未检测到 Python，会尝试用 **winget** 从 **Microsoft Store** 安装「Python 3.12」；若失败，再尝试 **winget 官方源**的 `Python.Python.3.12`；  
   - 在根目录创建 **`venv`**，并执行 `pip install -U pip setuptools wheel` 与 `pip install -r requirements.txt`。  
3. 若安装器刚把 Python 装进系统，**当前窗口可能仍找不到 `python`**，请**关闭黑色命令行窗口**，重新双击 **`test\setup_venv.bat`** 一次（让 PATH 生效）。  
4. 若提示缺少 **`seven17.json`**：将 **`config\seven17.example.json`** 复制一份，改名为 **`config\seven17.json`**，按文件内说明填写 API Key、seven17 账号等（**不要**把该文件发给不可信渠道或提交到公开仓库）。

安装成功后，即可按第 4 节运行各业务 **`.bat`**。

## 3. 配置文件说明（`config/seven17.json`）

从 **`seven17.example.json`** 复制得到 **`seven17.json`** 后，至少需要关注：

- **`PRODUCT_FEED_SQLITE`**：本地 SQLite 数据库路径，默认多为 `data/product_feed.db`  
- **`WECATALOG_ALBUM_ID`**：微猫店铺相册 ID，可与店铺 URL 中一致  
- **`WECATALOG_DETAIL_DELAY`**：抓取时节流；如 `"5"` 固定秒，`"3,8"` 或 `[30,50]` 表示闭区间内随机秒数（未传命令行 `--detail-delay` 时生效）  
- **`WECATALOG_SCRAPE_RESTART_AFTER_ITEMS`** 等：拉取 / LLM / 上传累计处理 N 条后进程以**退出码 75**结束，供外层 bat 循环重启；`0` 表示关闭  
- **`OPENAI_*`** / **`OPENAI_PROFILES`**：上架文案 LLM（**每条商品 1 次** `enrich`，无批量、无分类 LLM、无单独韩文补译）  
- 商品采集**仅**请求 `popUpsInfoV2`（title / 图 / 价 / 尺码 / 颜色）；不再调用 `commodity/view`  
- **规格拆列**（`pf_store_item`）：`commodity_sizes_json` / `commodity_colors_json`（01 爬取写入；**02 LLM** 纠错后**回写同列**，如中文尺码 S/M/L 覆盖错误爬取值）；`sizes_ko_json` / `colors_ko_json`（韩文，随 LLM 更新）；`llm_name_*` / `llm_desc_*`。**价格**：`price_cny` 与 `price_krw` 在 **01 采集** 时写入（每翻一页拉一次 CNY→KRW 实时汇率，韩元按**千韩元**取整）；LLM **不**返回韩元。**不保存**接口整包 JSON。**一键迁移**：双击 **`06_迁移数据库规格.bat`**  
- **`OPENAI_LISTING_COLOR_VISION`**：`false`（默认）文生文，颜色仅从原文**明确写出的销售色/可选色**提取（禁止材料/里料/五金猜色）；爬取已有色优先，爬取无色时 LLM 色写入 `commodity_colors_json`。`true` 时附**一张**商品图九宫格（最多 9 张合成），颜色**仅从图片**识别、**忽略标题**，`MAX_PX` 为合成图长边像素上限（需 Pillow）  
- **`LISTING_LLM_INPUT_PRICE_PER_M_256K`** / **`LISTING_LLM_INPUT_PRICE_PER_M_1M`**：LLM 输入 token 分档单价（元/百万，按**单次请求** `prompt_tokens`）：默认 `2`（≤256K）、`8`（256K~1M）；日志 `cost_yuan`、本轮 `token_usage.cost_yuan`  
- **`SEVEN17_*`**：seven17 站点账号、是否无头浏览器、库存、韩元换算等；**`ca_id` 仅**靠 `wecatalog_tag_category_map` + `seven17_path_ca_map`  

具体键名以 **`seven17.example.json`** 内 **`_说明`** 字段为准。

## 4. 常用批处理（`.bat`）说明

均在**仓库根目录**双击运行（会先 `cd` 到脚本所在目录）。

- **`test\setup_venv.bat`**：首次或换机：创建 `venv`、用清华源安装 `requirements.txt`；必要时通过 winget 安装 Python  
- **`01_采集微猫店铺.bat`**：浏览器登录上下文下抓取微猫店铺，写入 SQLite；支持环境变量 `STORE_URL`；若 bat 内仍写 `--detail-delay 5` 会**覆盖**配置里的 `WECATALOG_DETAIL_DELAY`  
- **`02_LLM补全上架信息.bat`**：逐条 LLM（原始标题 + 已整理字段 → 翻译与纠错，每条一次）；写回扁平行  
- **`03_上传韩国站正式.bat`**：只读 DB 上传 seven17（标题用 `name_ko`，**不调 LLM**）  
- **`04_无价格白名单设置.bat`**：打开白名单 GUI，勾选 map 分类开关  
- **`05_查看商品库.bat`**：本地 Web 浏览 SQLite 商品表（分页、按 LLM/上传时间排序）；默认 http://127.0.0.1:8765/  
- **`test\run_scrape_llm_upload_parallel.bat`**：并行跑三条流水线时参考  

若某 bat 内出现 **`exit 75` 后再次运行** 的逻辑，表示与配置中的 **`*_RESTART_AFTER_ITEMS`** 配合，用于长跑时刷新进程与配置。

**数据流（简图）**：`01 采集` → SQLite（结构化列 + 尺码修复）→ `02 LLM`（翻译与纠错）→ `03 上架`。

## 5. 浏览器与 Playwright

抓取与上架脚本会通过 **Playwright** 驱动 Chromium 系浏览器。本仓库逻辑一般为：

- 若根目录存在 **`chrome-win\chrome.exe`**，则优先使用该便携 Chromium；  
- 否则尝试调用本机已安装的 **Chrome / Edge**（channel 方式）。

若报错提示找不到浏览器，请安装 Chrome/Edge，或按项目维护者说明放置 `chrome-win` 目录。

## 6. 离线安装依赖（可选）

在**有网络**的机器上预先下载 wheel 包：

```bat
mkdir wheels
venv\Scripts\pip download -r requirements.txt -d wheels
```

将 **`wheels`** 目录与源码一并拷贝到离线机后，在已创建 `venv` 的前提下执行：

```bat
venv\Scripts\pip install --no-index --find-links=wheels -r requirements.txt
```

（若离线机尚未创建 `venv`，仍需先具备 Python，并执行 `python -m venv venv`。）

## 7. 常见问题

**Q：双击 bat 一闪就关。**  
A：在资源管理器地址栏输入 `cmd` 回车，在命令行里 `cd` 到仓库根目录后手动执行该 bat，可看到报错信息。

**Q：提示找不到 `venv\Scripts\python.exe`。**  
A：先成功运行一次 **`test\setup_venv.bat`**。

**Q：pip 很慢或超时。**  
A：确认 **`config\pip_tsinghua.ini`** 存在，且用 **`test\setup_venv.bat`** 安装（其会设置 `PIP_CONFIG_FILE`）。若仍失败，检查公司网络是否拦截 PyPI 镜像。

**Q：抓取间隔配置了 `[30,50]` 仍很快。**  
A：检查 **`01_采集微猫店铺.bat`** 是否仍带 **`--detail-delay`** 参数；命令行会覆盖 **`WECATALOG_DETAIL_DELAY`**，可删掉该行或改成与配置一致。

**Q：`seven17.json` 能否发给同事？**  
A：内含密钥与账号，仅通过**安全渠道**点对点传递；公开仓库应只保留 **`seven17.example.json`**。

## 8. 技术支持与更新

功能与参数以仓库内 **`seven17.example.json`**、各模块文件头注释及 **`.bat`** 内 `rem` 说明为准。若维护者更新了依赖，请重新运行 **`test\setup_venv.bat`** 以刷新 `venv` 中的包。

文档版本：与仓库 **`docs/用户说明.md`** 同步。Word 版由同目录 **`build_docx.py`** 生成：

- **`docs/用户说明.docx`**（中文文件名）  
- **`docs/USER_GUIDE_zh-CN.docx`**（纯英文文件名，便于邮件或网盘分发）

重新生成（需已安装 **`python-docx`**，可用清华源）：

```bat
set PIP_CONFIG_FILE=%CD%\config\pip_tsinghua.ini
venv\Scripts\pip install python-docx
venv\Scripts\python docs\build_docx.py
```
